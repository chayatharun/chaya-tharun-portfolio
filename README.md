# Chaya Tharun — Developer Portfolio

A responsive, single-page portfolio built with plain HTML, CSS, and JavaScript. Visual palette: Jet Black (`#030508`), Cerulean Blue (`#00A6E8`), and Neon Rose (`#FF3E8D`).

## Run locally

This is a static site; no package installation or build step is required.

- Open `index.html` in a browser, or
- Use the VS Code Live Server extension for a local development server.

## Deploy on Render

Create a **Static Site** connected to the GitHub repository containing these files.

- **Root Directory:** leave blank if `index.html` is in the repository root
- **Build Command:** leave blank
- **Publish Directory:** `.`

If you keep these files inside a subfolder, set Root Directory to that folder and Publish Directory to `.`.

## Before publishing

Review the email address and LinkedIn URL in `index.html`. The email is currently a placeholder (`chayatharun@example.com`), and the LinkedIn link points to the LinkedIn homepage. Replace both with your real contact details. Confirm the resume and certificate files in `public/` are the versions you want recruiters to see.
